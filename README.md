# 🎧 AudioEPUB

AudioEPUB es una aplicación para Android diseñada para extraer el texto de libros electrónicos en formato **EPUB** y reproducirlos en formato de audio utilizando la tecnología de Texto a Voz (Text-to-Speech). Ideal para escuchar tus libros favoritos mientras viajas, trabajas o descansas.

## ✨ Características Principales

* **Lector de EPUB local:** Carga fácilmente cualquier archivo `.epub` desde el almacenamiento interno de tu dispositivo.
* **Motor Text-to-Speech (TTS):** Conversión nativa de texto a audio de forma fluida.
* **Controles de Reproducción:** Reproduce, pausa y ajusta la velocidad de la narración.
* **Navegación:** Lectura secuencial y soporte para saltar entre capítulos.
* **Modo en Segundo Plano:** Sigue escuchando el libro con la pantalla apagada o mientras usas otras apps. *(Nota: elimina este punto si tu app aún no hace esto)*

## 📥 Instalación (APK)

Puedes probar la aplicación instalando el archivo APK directamente en tu dispositivo Android:

1. Ve a la pestaña de [Releases](../../releases) de este repositorio.
2. Descarga la última versión del archivo `audioepub.apk`.
3. Abre el archivo en tu teléfono. Es posible que debas conceder permisos para **"Instalar aplicaciones de orígenes desconocidos"**.
4. Completa la instalación y disfruta.
